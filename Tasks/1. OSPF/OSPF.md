### Instructions:

1. Subnet the network based on the following requirements.
*Coimbatore = 192.168.50.0
*Chennai = 192.168.100.0
*Bangalore = 192.168.150.0
*Delhi = 192.168.200.0
*WAN 1 = 50.0.0.0/30
*WAN 2 = 100.0.0.0/30
*WAN 3 = 150.0.0.0/30

2. Create a topology in the packet tracer as same as in the figure above.

3. Do configure the basic configuration for Coimbatore & Chennai Routers and Bangalore & Delhi Switches. (Should use given name in the topology for Hostname for all devices)

4. Configure enable password for Coimbatore & Chennai switches and Secret password for Bangalore & Delhi Switches. ("Enable Password should be the first four digits of your mobile no and Secret Password should be the first four letters of your name" ) Note: Encrypt the non-encrypted passwords

5. Assign first valid IP for all the router and second valid IP for all the switches based on their respective networks.

6. End devices of all the locations should get dynamic IP address using DHCP server.

7. Configure TELNET for Coimbatore and Bangalore Routers and SSH for Chennai and Delhi Routers ("For TELNET, VTY password should be the last four digits of your mobile no and for SSH the username should be your fav hero name and password is your fav cricketer name")

8. Configure OSPF using Process ID = X and back bone area for all the routers. ("X is your Task ID").

9. Verify the connectivity between different LAN networks.

10. Copy the configuration of all the routers and switches from RAM to NVRAM.
